## 1. Database Schema Changes

### H2 Schema (`src/main/resources/db/h2/schema.sql`)

```sql
CREATE TABLE visits (
  id               INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  pet_id           INTEGER,
  visit_date       DATE,
  description      VARCHAR(255),
  start_time       TIME,                    -- NEW: Appointment start time
  duration_minutes INTEGER DEFAULT 30,      -- NEW: Appointment duration
  vet_id           INTEGER                  -- NEW: Assigned veterinarian
);
ALTER TABLE visits ADD CONSTRAINT fk_visits_pets FOREIGN KEY (pet_id) REFERENCES pets (id);
ALTER TABLE visits ADD CONSTRAINT fk_visits_vets FOREIGN KEY (vet_id) REFERENCES vets (id) ON DELETE SET NULL;
CREATE INDEX visits_pet_id ON visits (pet_id);
CREATE INDEX visits_vet_id ON visits (vet_id);
```

**Evidence**: All schema files (H2, MySQL, PostgreSQL, HSQLDB) have been updated with:
- `start_time TIME` column
- `duration_minutes INTEGER DEFAULT 30` column
- `vet_id INTEGER` column with foreign key constraint and ON DELETE SET NULL

### MySQL Schema (`src/main/resources/db/mysql/schema.sql`)

```sql
CREATE TABLE IF NOT EXISTS visits (
  id INT(4) UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  pet_id INT(4) UNSIGNED,
  visit_date DATE,
  description VARCHAR(255),
  start_time TIME,
  duration_minutes INT DEFAULT 30,
  vet_id INT(4) UNSIGNED,
  INDEX(pet_id),
  INDEX(vet_id),
  FOREIGN KEY (pet_id) REFERENCES pets(id),
  FOREIGN KEY (vet_id) REFERENCES vets(id) ON DELETE SET NULL
) engine=InnoDB;
```

### PostgreSQL Schema (`src/main/resources/db/postgres/schema.sql`)

```sql
CREATE TABLE IF NOT EXISTS visits (
  id               INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  pet_id           INT REFERENCES pets (id),
  visit_date       DATE,
  description      TEXT,
  start_time       TIME,
  duration_minutes INT DEFAULT 30,
  vet_id           INT REFERENCES vets (id) ON DELETE SET NULL
);
CREATE INDEX ON visits (pet_id);
CREATE INDEX ON visits (vet_id);
```
